# ALX Simple Quiz

This is a simple interactive quiz web application built with **HTML**, **CSS**, and **JavaScript**.  
It asks a basic question and gives instant feedback based on the user's selected answer.

---

## 🧠 Features
- Multiple-choice question interface  
- Instant feedback after submission  
- Simple, responsive design  
- Clean and beginner-friendly JavaScript logic

---

## 🧩 Files Included

ALX_Simple_Quiz/
├── index.html # The main HTML structure
├── styles.css # Styling for the quiz layout
└── quiz.js # JavaScript logic for interactivity


---

## ⚙️ How It Works
1. The user selects an answer to the question “What is 2 + 2?”  
2. Clicks the **Submit Answer** button  
3. The app checks the answer and displays:
   - ✅ *"Correct! Well done."* if the answer is right  
   - ❌ *"That's incorrect. Try again!"* if the answer is wrong
